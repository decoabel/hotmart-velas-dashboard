# Hotmart Opportunity Dashboard — Velas Artesanales

Dashboard interactivo para mostrar oportunidades de afiliación en Hotmart dentro del nicho de velas artesanales.

## Incluye

- Portada 100% responsive.
- La portada funciona como menú principal y entrada al dashboard.
- Botón Music ON / OFF.
- Música ambiental suave generada con Web Audio API.
- Filtros por categoría, demanda, oferta y brecha.
- Tarjetas interactivas con Demanda, Oferta, Brecha y nivel de oportunidad.
- Panel de lectura comercial por subnicho.
- Botón para regresar al menú principal.
- Optimizado para móvil, tablet y desktop.
- Preparado para GitHub Pages.

## Nota metodológica

Los valores de demanda y oferta son índices estratégicos estimados (0–100), no métricas oficiales de Hotmart. Sirven para comparar oportunidades entre subnichos.
